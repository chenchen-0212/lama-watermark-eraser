社媒图文去水印工作台 — 使用说明
================================

【这是什么】
单文件桌面应用（Wails = Go 后端 + Vue3 界面），把「社媒图文下载」与
「LaMa AI 批量去水印」串成一条流水线：

  输入社媒链接 → 下载图片（视频链接自动拦截提示）→ 预览图片列表
  → 批量/勾选去水印 → 预览结果 → 导出 zip

基于开源项目二开：advimman/lama（Apache-2.0，去水印引擎）
                zinan92/content-downloader（MIT，下载思路参考）

【界面流水线（双击 exe）】
1. 粘贴链接，点「下载图片」
2. 下载完成自动进入预览网格，点击图片可勾选/取消
3. 在左侧大图上按住左键拖拽，框选水印位置（可框选多个区域，全部都会被去除）
   · 拖动框选区域四边/四角的手柄可调整大小
   · 点区域右上角 ✕ 删除单个；点「清空」删除全部
   · 定位模式：默认「按比例适配」（自动适配不同分辨率图集）；
     同尺寸批量图可改用「绝对位置」
   · 边缘外扩：默认 12px，覆盖半透明水印边缘，有残留调大到 20~30
4. 点「全部去水印」或「仅勾选(n)」，进度实时可见；处理中可点「取消抹除」立即中止任务
5. 结果预览（点击图片可放大查看原图，Esc 或点空白处关闭）→ 点「导出 zip 压缩包」选择保存位置

【命令行模式】
LaMaWatermarkRemover.exe --url <社媒链接>                          # 仅下载图片
LaMaWatermarkRemover.exe --input <图片文件夹> --output <输出目录> --box x1,y1,x2,y2
LaMaWatermarkRemover.exe --url <链接> --output <输出目录> --relative-box 0.68,0.08,0.96,0.16
LaMaWatermarkRemover.exe --input <图片文件夹> --output <输出目录> \
  --relative-boxes "0.02,0.02,0.3,0.25|0.65,0.05,0.95,0.3"   # 多个水印区域（| 分隔）
可选参数：
  --dilate N       掩膜边缘外扩（默认 12）
  --margin N       修复上下文边距（默认 64）
  --mask file.png  不规则水印掩膜（白色=水印区域）
  --recursive      递归子文件夹
  --zip            完成后自动打包 zip
框选方式（--box/--relative-box 单个、--boxes/--relative-boxes 多个）：
  x1,y1,x2,y2 为左上/右下坐标；带 relative 的为 0..1 比例坐标。
退出码：全成功 0；有失败 2。

【平台支持矩阵（诚实版）】
┌──────────┬────────────────────────────────────────────────┐
│ 公众号    │ ✅ 完全可用（零配置，已实测）                    │

│          │   App「分享→复制链接」的最新完整链接（xsec_token  │

│ 抖音      │ ⚠️ 风控最强，分享页接口不稳定；失败时给出明确提示，│
│          │   建议保存图片后用本地文件夹模式去水印            │
│ 视频链接  │ 🚫 自动识别并提示不支持（仅支持图文）             │
└──────────┴────────────────────────────────────────────────┘

【技术说明与已知边界】
· 去水印引擎：LaMa ONNX（CPU 推理），仅修复水印邻域（≤512px 原生分辨率；
  超过 512px 的超大水印区域会等比缩放处理，细节略降）。
· 单张耗时约 2~4 秒（普通 CPU）。
· JPEG 输出质量 95（Go 编码器为 4:2:0 采样）；webp 输入可读，输出自动回退 png。
· 首次启动会把内嵌的 AI 模型(约 200MB)解压到
  %LOCALAPPDATA%\LaMaWatermarkRemover\，之后启动直接复用。
· 杀毒软件可能对单文件 exe 误报，添加信任即可。
· 请仅处理你拥有合法权利的内容；请遵守各平台用户协议与相关法律法规。
